A 2D retro-inspired space shooter where you face an increasing number of enemies until you're destroyed.

## Game overview

This project came about through an independent study while I was working toward my bachelor's degree. I became curious about using Python for game development, so I started researching and discovered Pygame, a cross-platform set of Python modules for making games.

Developing without an engine was a challenge, but also a great learning experience. Python is rarely used for games, and I wanted to see what could be done with it. I was quite pleased with the end result!

## Gameplay features

- An increasing number of enemies
- Power-ups that enhance the player's abilities
- High score tracking

You can play Space Force in your browser on itch.io.
