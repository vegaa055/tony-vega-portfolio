## Context

Built at the University of Arizona's Cyber Convergence Center (C3) as part of a Cyber Virtual Learning Environment: a fictional-but-realistic web property used in training exercises. The goal was a fully serverless, low-maintenance portal that could accept anonymous submissions without maintaining session state or a dedicated database.

## Stack

AWS Lambda (Python), API Gateway, S3 (for both hosting and submission storage), CloudFront, and least-privilege IAM roles for each function.
